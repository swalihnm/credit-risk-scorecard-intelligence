# Data Sources

This project deliberately combines three data sources with different roles. They are **not**
merged into a single portfolio — see the "join decision" note below.

## Source A — Application level: Home Credit Default Risk (Kaggle)

- 307,511 applications, 122 raw features across 7 relational tables:
  `application_train`, `bureau`, `bureau_balance`, `previous_application`,
  `POS_CASH_balance`, `installments_payments`, `credit_card_balance`.
- Used for: the **application scorecard** (binning, WOE, logistic regression, calibration,
  reject inference, LightGBM challenger).
- Status: **real data** — downloaded from Kaggle (`kaggle.com/c/home-credit-default-risk`),
  extracted to `sources/home_credit/`, and run through the full pipeline. 307,511 applications,
  matching the known real dataset exactly (verified row count and the ~8.07% base default rate).
  `ingest/kaggle_download.py` (API-based) and `ingest/synthetic_home_credit.py` (the stand-in
  used earlier in this build, before real data was downloaded) both write to the identical file
  layout, so nothing in `features/`, `scorecard/`, `challenger/`, or the marts needed to change
  when the swap happened.
- **One remaining synthetic piece:** the reject pool used for reject inference
  (`sources/home_credit/*_rejects.csv`, `reject_hidden_truth.csv`) is still synthetic, generated
  by `ingest/synthetic_home_credit.py`'s `build_reject_pool`. Neither the real Kaggle dataset
  nor any synthetic stand-in for it includes a population of declined applicants with known
  features but no observed outcome — that's a structural gap in the dataset itself, not
  something downloading the real data fixes. See `docs/03-reject-inference.md`.

## Source B — Performance level: Fannie Mae Single-Family Loan Performance

- Real source requires free registration at the Fannie Mae Data Dynamics portal and is not
  accessible via a scriptable API — a human has to log in and download extract files.
- Used for: the **time dimension** — vintage curves, roll rate matrices, survival/hazard
  modelling, LGD estimation, and the macro-linked stress testing.
- Status for this build: **synthetic stand-in**, generated by `ingest/synthetic_fannie_mae.py`
  to the *exact schema* a real Fannie Mae loan-performance extract would have (loan id,
  origination date, reporting date, UPB, delinquency bucket, macro-correlated default hazard).
  This keeps the full pipeline — vintage curves, roll rates, survival model, ECL engine,
  stress scenarios, and every downstream Power BI mart — provably working end-to-end now.
  **Swap-in path:** once real extracts are downloaded, point `ingest/fannie_mae_ingest.py`
  (real-data reader, same output schema) at the raw files and nothing downstream changes.
- This is disclosed explicitly in `governance/MODEL_CARD.md` and `docs/06-assumptions-and-limitations.md`.
  Presenting synthetic data as real would be the actual red flag here — being explicit about
  the substitution is what makes it defensible.

## Source C — Macroeconomic: FRED API

- Real source: free, instant-signup API key from https://fred.stlouis.gov/docs/api/api_key.html.
  Series used: `UNRATE`, `CSUSHPINSA`, `DGS10`, `GDPC1`.
- Status for this build: **synthetic stand-in** aligned to the synthetic Fannie Mae vintages
  (2005–2010, capturing a crisis-shaped path, and 2015–2019, benign), generated by
  `ingest/synthetic_fred.py` to the same schema FRED's API returns.
  **Swap-in path:** `ingest/fred_ingest.py` (real-data reader using `fredapi`) is written and
  ready — set `FRED_API_KEY` in `.env` and rerun ingestion; nothing downstream changes because
  both readers write to the same `macro` table in the warehouse.

## The join decision that makes this project unusual

Home Credit and Fannie Mae are **different portfolios, different countries, different products**
(unsecured consumer lending vs. US agency mortgages). They are used side by side to demonstrate
two complementary disciplines — application scorecarding vs. portfolio lifecycle/vintage
analytics — never silently merged into one book. Every mart and report page that touches
Fannie-Mae-derived data is labeled by portfolio.

## Practical sampling (documented even though this build starts synthetic)

Real Fannie Mae ingestion, when wired in, should sample vintages 2005–2010 (captures the 2008
crisis) plus 2015–2019 (benign) rather than the full multi-decade file.
